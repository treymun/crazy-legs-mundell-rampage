Install

These are the documented steps for the public v1.4.3 Windows x64 prerelease. The ZIP is the release file linked above. This website does not host a second copy.

  1. Download the Windows release ZIP from the verified release link and extract it completely.
  2. Open CrazyLegsMundellRampage-1.4.3.exe for this version.
  3. Press Enter at the title screen to start. The documented first launch is a resizable 4:3 window.
  4. Open Setup to change display, input, or audio. The picture section below has the documented fullscreen controls.

The packaged EXE is documented as standalone. Players do not need a Python environment to run it. This site does not promise a signed executable, and it does not ask anyone to bypass a Windows security warning.

Saves

Named saves use F5. Quicksave and quickload use F6 and F9.

Default saves, settings, and screenshots go to %LOCALAPPDATA%\HickstonIncident.

The notes document four named campaign slots, four slots per replay chapter, and a separate quicksave. Existing supported V1–V3 saves are backed up before conversion to V4.

The notes say to throw a lit dynamite stick before saving. This page does not promise a save while a fuse is still burning.

Picture and options

The scene is documented as a 320×200 software-rendered view with native pixel lettering.

Display, input, and audio have separate settings. The first launch is a resizable 4:3 window. Fullscreen (Fill) fills the monitor. Fullscreen (Aspect) keeps the selected proportions. F11 toggles window and fullscreen.

No hardware requirements are listed here.

Source builds

A source build is documented for Python 3.12 x64, with pinned dependencies and Build_CrazyLegsMundellRampage.bat. That path is for development. This site does not host the script or the source tree.
